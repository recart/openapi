# Account

## Retrieve the accounts of the API key

> List the accounts the API key gives access to. An API key belongs to one account,\
> so the list carries a single entry: the account's id, name, domain, currency and time zone.\
> Use the account's \`id\` wherever an integration needs to identify the account.<br>
