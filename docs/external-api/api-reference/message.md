# Message

## Send message(s) to a subscriber

> Trigger SMS/MMS messages. Maximum 10 messages can be sent in a single request. Requester must comply with TCPA regulations, and make sure the message is not sent in quiet hours.\
> \
> The site must have an active or trial SMS subscription, otherwise the request fails\
> with \`417\`.\
> \
> Messages are queued in the order given rather than sent inline, so \`202\` confirms\
> that they were accepted for delivery, not that they were delivered. The response\
> returns one entry per message; poll \`GET /messages/{id}\` with the returned IDs to\
> follow their delivery status.<br>
